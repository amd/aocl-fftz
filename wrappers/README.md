FFTZ THIRD-PARTY WRAPPERS
=========================

The FFTZ Third-Party Wrappers offer a streamlined interface for the APIs of third-party libraries like FFTW,
while internally leveraging the FFTZ library for enhanced performance and flexibility in computing discrete Fourier transforms (DFTs).
Supports single and double precision computation of real and complex numbers in single and multi threaded execution modes.

Key features:<br>
- Support for single-precision and double-precision computations on both real and complex data.<br>
- Execution modes for single-threaded and multi-threaded FFT computations.<br>

Each third-party FFT library has a dedicated wrapper to ensure seamless interoperability with its APIs.<br>
To build or verify a specific wrapper library, navigate to the corresponding third-party wrapper directory.<br>
